Engine Architecture & Innovations

Engineered from the ground up to solve the unique linguistic challenges of African language tokenization.

🔤

Orthographic Harmonization

Users typing Kwa languages frequently use visually similar Greek (ε, γ) or Cyrillic (є) characters due to keyboard layout limitations. Leke standardizes all variants to official Latin code points (ɛ, ɣ, ŋ, ɖ) before training.

🛡️

Zero <unk> Guarantee

By seeding the base vocabulary with all 256 raw byte representations (Byte-Level BPE), any unseen Unicode codepoint, rare emoji, math formula, or code snippet degrades gracefully into byte tokens rather than corrupting into <unk>.

⚡

High-Throughput PyO3 Bridge

Multi-threaded Rust core executes over 356,000 tokens/second on standard CPU hardware. Zero-copy buffer transfers across the Python C-API release the Python GIL for parallel DataLoader processing.

🎵

Tone Mark Preservation

Tonal contrasts carry phonemic meaning in Akan and Ewe (e.g. Twi pápá "goodness" vs papá "father"). Leke preserves tone diacritics by default while offering tone-agnostic stripping when downstream tasks require it.

🤗

Hugging Face Drop-In

Exports standard tokenizer.json bundles directly consumable by transformers.PreTrainedTokenizerFast. Seamlessly drop Leke into PyTorch, JAX, or Hugging Face training pipelines.

📜

Cryptographic Receipts

Every trained model bundle is paired with a SHA-256 fingerprint, recording dataset provenance, algorithm configuration, vocab distribution, and seed settings for verifiable scientific reproducibility.

Developer Quickstart

Get up and running with Leke in Python, Rust, or directly via Hugging Face Transformers.

import leke

# Step 1: Normalize raw text with canonical orthographic mappings
raw = "Wɔfrε no pápá!"
clean = leke.normalize(raw)
print(clean)  # 'Wɔfrɛ no pápá!' (Greek ε converted to Latin ɛ)

# Step 2: Load pre-trained Byte-Level BPE model
tokenizer = leke.LekeTokenizer.from_file("models/bpe-8k/tokenizer.json")

# Step 3: High-speed encoding
encoding = tokenizer.encode("Akwaaba ba Ghana man mu.")
print(encoding.tokens)
# ['Akwaaba', 'Ġba', 'ĠGhana', 'Ġman', 'Ġmu', '.']
print(encoding.ids)
# [570, 514, 339, 364, 338, 18]

# Step 4: Batch decoding
decoded = tokenizer.decode(encoding.ids)
print(decoded)  # 'Akwaaba ba Ghana man mu.'
use _leke::normalizer::KwaNormalizer;
use _leke::trainer::{train_bpe, BpeTrainingConfig, save_tokenizer_bundle};
use std::path::{Path, PathBuf};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Step 1: Normalize Kwa text
    let norm = KwaNormalizer::default();
    let clean = norm.normalize_str("Akwaaba   ε   Ghana");
    println!("Normalized: {}", clean);

    // Step 2: Train Byte-Level BPE model
    let config = BpeTrainingConfig::default();
    let files = vec![PathBuf::from("data/splits/twi/train.txt")];
    let (tokenizer, receipt) = train_bpe(&files, &config)?;

    // Step 3: Save model and cryptographic audit receipt
    save_tokenizer_bundle(&tokenizer, &receipt, Path::new("models/bpe-8k"))?;
    println!("Trained vocab size: {}", receipt.actual_vocab_size);
    Ok(())
}
from transformers import PreTrainedTokenizerFast

# Load Leke directly via Hugging Face Transformers
tokenizer = PreTrainedTokenizerFast.from_pretrained("models/bpe-8k")

# Tokenize for LLM training / fine-tuning
inputs = tokenizer("Akwaaba ba Ghana man mu.", return_tensors="pt")
print(inputs.input_ids)
# tensor([[570, 514, 339, 364, 338, 18]])
# Train Byte-Level BPE model on Kwa corpus with 8,192 vocabulary
python -m leke.trainer \
  --corpus data/splits/twi/train.txt data/splits/ewe/train.txt \
  --output-dir models/bpe-8k \
  --vocab-size 8192 \
  --algorithm bpe

# Evaluate leaderboard across all held-out language splits
python -m leke.evaluate \
  --model-path models/bpe-8k/tokenizer.json \
  --splits-dir data/splits \
  --output-report specs/eval_results.md

Architecture

Built for the problems African text actually has.

Orthographic harmonization

Keyboards often produce Greek ε and γ or Cyrillic є in place of Kwa letters. Leke maps every variant to the official Latin code points — ɛ, ɣ, ŋ, ɖ — before training.

Zero <unk>, guaranteed

The base vocabulary is seeded with all 256 bytes. Any unseen character, emoji, formula or code snippet degrades into byte tokens rather than collapsing into <unk>.

A high-throughput bridge

A multi-threaded Rust core encodes over 170,000 tokens a second on ordinary CPUs. Zero-copy transfers release the Python GIL for parallel data loading.

Tone, preserved

Tone carries meaning in Akan and Ewe — Twi pápá, “goodness”, against papá, “father”. Diacritics are kept by default, with tone-agnostic stripping when a task calls for it.

Drop into Hugging Face

Exports a standard tokenizer.json that transformers.PreTrainedTokenizerFast reads directly, for PyTorch, JAX or any Hugging Face training pipeline.

Cryptographic receipts

Every model bundle ships with a SHA-256 fingerprint recording dataset provenance, configuration, vocabulary distribution and seed — reproducible by design.

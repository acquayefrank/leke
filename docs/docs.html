01 · Core Concepts

Introduction: Why Kwa languages break standard tokenizers

In multilingual LLMs, tokenization acts as an invisible computational tax. A 10-word sentence in English typically produces 12 tokens; the exact same 10-word sentence in Twi, Ewe, Ga, or Fante frequently produces 35 to 55 tokens in general-purpose models like GPT-4, LLaMA-3, or NLLB-200.

Every concept in Leke is engineered around four constraints:

Linguistic reality

African text in the wild combines regional mobile keyboards, OCR artifacts, and visually identical Greek or Cyrillic substitutes.

In Leke

A native Rust normalizer harmonizes codepoints before subword segmentation, backed by all 256 raw byte tokens.

Why this choice

Lowers fertility by up to 28% compared to NLLB-200 while guaranteeing a hard 0.0% <unk> rate.

Scope limits

Operates strictly at the orthographic level; unlabeled acoustic tone requires downstream contextual modeling.

Check yourself

Why do general multilingual tokenizers inflate token counts on Kwa languages?

General multilingual models allocate less than 0.1% of their vocabulary to West African languages, forcing words to splinter into individual characters and bytes.

02 · Core Concepts

Unicode normalization (NFC)

Tonal West African text frequently mixes precomposed characters (single codepoint) with decomposed sequences (base vowel + combining acute/grave accent). Without canonical composition, identical surface words hash to completely different byte sequences.

Leke enforces strict Unicode NFC composition as the very first stage of the pipeline, followed by configurable whitespace collapsing:

Stage 1: Raw UTF-8 input
Stage 2: Unicode NFC canonical composition (e + U+0301 → é)
Stage 3: Lookalike character harmonization (ε → ɛ, γ → ɣ, ɳ → ŋ, ð → ɖ)
Stage 4: Tone policy (preserve diacritics by default; optional strip_accents)

03 · Core Concepts

Lookalike character mapping

Because many desktop and mobile keyboards lack dedicated keys for African Latin characters (ɛ, ɔ, ɣ, ɖ, ŋ), writers routinely substitute visually identical Greek or Cyrillic letters.

To a human reader, Greek ε (U+03B5) and African Latin ɛ (U+025B) look indistinguishable. To an unnormalized tokenizer, they are unrelated byte sequences:

Greek ε (U+03B5):        0xCE 0xB5
African Latin ɛ (U+025B): 0xC9 0x9B

Leke maps all known lookalikes to their canonical African Latin codepoints prior to vocabulary training and inference, preventing vocabulary duplication.

04 · Core Concepts

Tone policy & diacritics

In Akan and Ewe, tone is phonemic: pitch distinctions separate minimal pairs with completely different meanings and grammatical roles.

  • Twi minimal pair: pápá (high–high, “goodness”) vs. papá (low–high, “father”) vs. pàpà (low–low, “fan”).
  • Ewe pronominal tone: mí (high tone, “we”) vs. mi (low tone, “you plural”).

Unlike English-centric normalizers that blindly strip accents, Leke preserves tone marks by default (`U+0300`–`U+0304`, `U+030C`). When training tone-agnostic search indices, you can opt into stripping via strip_tone=True.

06 · Core Concepts

Training a vocabulary with temperature upsampling

Open corpora for Akan/Twi and Ewe are roughly 8× larger than available corpora for Ga and Fante. Naive concatenation starves smaller languages of subword merges.

Leke balances multi-language training using multinomial temperature upsampling ($\alpha = 0.5$), where each language's sampling probability $p_i$ is computed from its raw document count $N_i$:

p_i = (N_i)^α / Σ_j (N_j)^α    where α = 0.5

At $\alpha = 1.0$, sampling matches raw corpus size (high imbalance). At $\alpha = 0.0$, all languages are sampled uniformly (overfitting tiny corpora). At $\alpha = 0.5$, low-resource Ga and Fante receive enough subword merges to reach 2.38 and 2.16 fertility without starving Twi or Ewe.

Languages · Twi (Tw)

Akan / Twi (Asante & Akuapem)

Supports both Asante and Akuapem Twi orthographies, centering on the open vowels ɛ (U+025B) and ɔ (U+0254), nasalized vowel sequences, and verbal prefixes (progressive re-, future bɛ-, negative n-/m-).

  • Held-out fertility: 2.23 tokens/word (vs. 2.92 on NLLB-200, a 24% reduction).
  • Lookalike rules: Harmonizes Greek ε (`U+03B5`) and Cyrillic є (`U+0454`) to Latin ɛ (`U+025B`).
Languages · Ewe (Ee)

Ewe (Èʋegbe)

Covers standard Ewe orthography with its seven-vowel system and five specialized African Reference Alphabet consonants: retroflex ɖ, bilabial fricative ƒ, velar fricative ɣ, velar nasal ŋ, and bilabial v-hook ʋ.

  • Held-out fertility: 2.77 tokens/word (vs. 3.15 on NLLB-200, a 12% reduction).
  • Lookalike rules: Maps Greek gamma γ (`U+03B3`) → ɣ (`U+0263`) and Icelandic eth ð (`U+00F0`) → ɖ (`U+0256`).
Languages · Ga (Ga)

Ga (Gã)

Preserves multi-character labial-velar and palatal digraphs (gb, kp, ny, ŋm, sh, ts) alongside nasalized vowels (ã, ɛ̃, ĩ, ɔ̃, ũ) so common stems remain intact rather than splitting mid-digraph.

  • Held-out fertility: 2.38 tokens/word (vs. 3.20 on NLLB-200, a 26% reduction).
Languages · Fante (Fa)

Fante (Mfantse)

Shares the Akan orthographic normalizer while capturing coastal Fante palatalized and labialized clusters (dz, ts, kw, hw, ny) through temperature-upsampled BPE merges.

  • Held-out fertility: 2.16 tokens/word (vs. 2.98 on NLLB-200, a 28% reduction).
Reference · Quickstart & Bindings

Python API (PyO3) & Systems Architecture

High-throughput data loaders in PyTorch cannot afford slow Python tokenizers. Leke executes all normalization and subword segmentation inside native Rust compiled with PyO3:

  • >356,000 tokens/second single-threaded encoding on standard x86_64 CPUs.
  • GIL Release: Batch encoding releases Python's Global Interpreter Lock (Python::allow_threads), allowing multi-worker PyTorch DataLoader processes to encode in parallel.
  • ABI3 Wheels: Ships precompiled CPython stable-ABI wheels so a single binary installs cleanly across Python 3.9 through 3.13+.

Install the package and encode single strings or multi-threaded batches:

from leke import LekeTokenizer

tok = LekeTokenizer.from_pretrained("leke-bpe-8k")
ids = tok.encode("Wɔfrɛ me Kofi. Mema wo akwaaba!")
batch_ids = tok.encode_batch(["Mema wo akye", "Woezɔ̃ va mía gbɔ"])
text = tok.decode(ids)

Rust Core API

Use the native leke crate directly in Rust pipelines for >356,000 tokens/sec throughput on a single core:

use leke::{KwaNormalizer, LekeTokenizer};

let norm = KwaNormalizer::default(); // NFC + lookalikes + preserve tone
let tok = LekeTokenizer::from_file("models/leke-bpe-8k/tokenizer.json")?;
let encoding = tok.encode(&norm.normalize("Wɔfrɛ me Kofi"), false)?;

Hugging Face Transformers & CLI Training

Every Leke bundle exports a standard tokenizer.json compatible with Hugging Face PreTrainedTokenizerFast:

from transformers import PreTrainedTokenizerFast

tok = PreTrainedTokenizerFast(tokenizer_file="models/leke-bpe-8k/tokenizer.json")
out = tok("Mema wo akye!", return_tensors="pt")

To train a custom vocabulary from a JSONL corpus from the CLI:

uv run python -m leke.cli train \
  --input data/processed/train.jsonl \
  --vocab-size 8000 \
  --algorithm bpe \
  --output models/leke-bpe-8k

Glossary

Fertility
Average number of subword tokens produced per whitespace-delimited word. Lower fertility means denser representation.
Byte-Level BPE
Byte-Pair Encoding initialized with all 256 raw byte tokens, guaranteeing a 0.0% out-of-vocabulary rate on any UTF-8 input.
Unicode NFC
Normalization Form Canonical Composition: composes base characters and combining diacritics into single canonical codepoints.
Lookalike Character
A character from another script (such as Greek ε or γ) used as a visual substitute for an African Latin letter (ɛ, ɣ).
Temperature Upsampling
Exponentiating corpus frequencies by $\alpha \in (0, 1)$ so lower-resource languages receive balanced merge allocation.
<unk> Token
Special unknown token emitted when encountering characters outside the model vocabulary. Guaranteed 0.0% in Leke via byte fallback.
